Expected Behavior:

  • ✅ Alt field should appear below the Quote field in properties panel
  • ✅ Alt field should appear for each caption in the captions list
  • ✅ Alt text should be editable and save with the project
  • ✅ Alt text should NOT affect video rendering (display only)
  • ✅ Alt field should work exactly like description fields

How to Test:

  1. Open the Video Editor (index.html)
  2. Copy one of the JSON examples above
  3. Use "Load from JSON" or paste into a .json file and load it
  4. Check that the Alt field appears in the properties panel
  5. Edit the alt text and verify it saves
  6. Export the JSON and verify alt field is included
